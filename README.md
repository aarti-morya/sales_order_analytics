# Sales & Order Management Analytics System

A SQL-based Sales & Order Analytics project developed using MySQL Workbench. The project demonstrates database design, data management, advanced SQL querying, business analytics, and query performance optimization.

## Project Overview

This project implements a relational database for an e-commerce Sales & Order Management system. It contains customer, product, order, order item, and payment data.

## Tools & Technologies

- MySQL
- MySQL Workbench
- SQL

## Database Structure

The database contains five main tables:

- Customers
- Products
- Orders
- Order_Items
- Payments

Primary keys and foreign keys were used to maintain relationships and data integrity.

## Key SQL Operations

### 1. Database & Table Design
- Created relational tables using DDL
- Implemented Primary Keys
- Implemented Foreign Keys
- Applied constraints and data types
- Designed normalized database structure

### 2. Data Insertion
- Inserted sample business transaction data
- Populated all five tables using INSERT statements

### 3. Data Analysis
Performed SQL analysis using:

- Filtering and sorting
- GROUP BY and aggregate functions
- SUM, COUNT and other aggregations
- Multi-table JOINs
- Business performance analysis

### 4. Reusable SQL Views

Created a monthly sales summary view to analyze:

- Year
- Month
- Number of orders
- Total revenue

### 5. Product Performance Analysis

Used JOINs and aggregations to calculate:

- Total units sold
- Product-wise revenue
- Top-performing products

### 6. Advanced SQL Analytics

Used SQL window functions such as:

- RANK()
- OVER()
- ORDER BY

to rank customers based on their total revenue.

### 7. Query Optimization

Implemented indexing and used EXPLAIN to analyze query execution and improve database query performance.
